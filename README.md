# ffxiHotbar

Windower 4 addons for Final Fantasy XI.

- **[BindHUD](BindHUD/)**: an on-screen overlay of your keyboard binds. It reads your GearSwap files and `init.txt` and shows which key and modifier trigger each spell, ability or toggle. It is display-only: it sends no packets, runs no commands and writes nothing to the chat log.

See [BindHUD/README.md](BindHUD/README.md) for install steps and commands.
