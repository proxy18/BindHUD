# BindHUD

A Windower 4 addon for Final Fantasy XI that shows your keyboard binds on screen. It reads your GearSwap files and `init.txt` and shows which key and modifier trigger each spell, ability or toggle, either on a full keyboard or as an alphabetical cheat sheet.

It is display-only: it sends no packets, runs no commands and writes nothing to the chat log.

The addon lives in [BindHUD/](BindHUD/). See [BindHUD/README.md](BindHUD/README.md) for install steps and commands.
